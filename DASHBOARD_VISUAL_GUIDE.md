## Animation Timeline

```
Page Load (0s - 2s):
0.0s: Background fades in
0.1s: Header slides down
0.2s: Tabs appear
0.3s: Portfolio cards stagger in (0.1s each)
0.5s: Positions fade in
0.7s: Opportunities slide up
0.5s: Morning brief overlay appears (spring bounce)

User Interactions:
- Hover: Scale 1.02, lift 3px (0.2s ease)
- Click: Scale 0.95 (0.1s), then action
- Tab switch: Fade out/in (0.3s)
- Brief close: Scale 0.9 + fade out (0.2s)
- Brief open: Scale 0.9→1 + fade in (0.3s spring)
```
