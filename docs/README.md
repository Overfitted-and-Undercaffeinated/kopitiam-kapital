## Team Responsibilities

### AI Engineer
Responsible for:
- Agent logic and orchestration
- LLM integration (Anthropic, OpenAI, Groq)
- RAG pipeline (Exa.ai + pgvector + Mem0)
- MCP server development
- Celery task scheduling
- Alert rules and risk calculations

### Frontend + Database Engineer
Responsible for:
- Next.js web UI
- React Native mobile app
- Supabase database schema
- Real-time subscriptions
- Push notifications
- API client libraries
