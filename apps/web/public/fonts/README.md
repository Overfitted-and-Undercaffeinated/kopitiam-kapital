# BBH Sans Bogle Font Files

This directory should contain the BBH Sans Bogle font files in WOFF2 format.

## Required Files

Place the following font files in this directory:

- `BBHSansBogle-Regular.woff2` (weight: 400)
- `BBHSansBogle-Medium.woff2` (weight: 500)
- `BBHSansBogle-Bold.woff2` (weight: 700)

## Font Formats

The application is configured to use WOFF2 format for optimal performance and compression.

If you only have TTF or OTF files, you can convert them to WOFF2 using:
- [CloudConvert](https://cloudconvert.com/ttf-to-woff2)
- [FontSquirrel Webfont Generator](https://www.fontsquirrel.com/tools/webfont-generator)
- Or use command line tools like `fonttools`
